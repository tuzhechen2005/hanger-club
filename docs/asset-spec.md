# Hanger Club 3D 资产规格

这是 Blender 资产管线与网页之间的契约。网页代码按这里的单位、锚点、节点名和动画名读取模型；任何一项要改，先改本文档，再同时改两边。

版本：v1（2026-10-12）。范围：衣架 + 短袖 T 恤基础网格 + 两段烘焙动画 + 单款商品贴图。

## 1. 坐标与单位

- 1 Blender 单位 = 1 米。Blender 中 Z 向上，衣服正面朝 **−Y**（即前视图看到正面）。
- glTF 导出使用默认的 +Y Up。导出后：Y 向上，衣服正面朝 **+Z**（朝向网页相机）。
- 原点 `(0,0,0)` = **挂钩接触点**：挂钩弯钩内侧顶部的接触点，也就是挂在横杆上时压在横杆顶面上的那一点。木身和衣服全部位于原点下方；挂钩绕过横杆的顶部金属允许高出原点约 0.004 m（线材直径）。此修正已由项目拥有者于 2026-10-12 确认。
- 网页横杆：直径 0.022 m 的圆管，轴线沿 X，顶面在 Y = 0。

## 2. 衣架 `public/models/hanger.glb`

| 项 | 规格 |
| --- | --- |
| 节点名 | `Hanger`（根），子网格 `HangerWood`、`HangerHook` |
| 总宽 | 0.44 m（左右肩尖） |
| 木身 | 截面约 0.014 m（高）× 0.022 m（厚），肩线自中心向两端自然下斜，两端圆润 |
| 木身顶部中心 | Y ≈ −0.075 m |
| 挂钩 | 金属线材直径 0.004 m。直杆从木身中心沿 Y 轴竖直升起（x = 0、z = 0），到横杆下方向前（+Z）避让，再从前往后绕过横杆，弯钩位于 **YZ 平面**（像可旋转挂钩那样与横杆垂直）。弯钩内侧顶点正好在原点 |
| 材质 | `Wood`：暖中棕木色、细木纹，roughness 约 0.55；`Metal`：铬，metallic 1、roughness 约 0.25 |
| 面数 | 合计 ≤ 3,000 三角形 |

衣架同时作为布料模拟的碰撞体；所有衣服使用同一个衣架。

网页在横杆上会让木身和衣服绕 Y 轴侧转约 80°，挂钩保持不动（相当于可旋转挂钩）。所以 `HangerHook` 必须是独立网格，木身与衣服里也不能有依赖挂钩方向的几何。

## 3. T 恤基础网格

所有短袖 T 恤共用一套网格与动画，商品之间只换贴图。

### 3.1 版型（默认 M 码 oversize boxy 落肩款）

参考照片是宽松落肩的 boxy 版型，衣长约为胸宽的 1.25–1.3 倍（2026-10-13 从 0.70 / 0.62 改为 0.76 / 0.60：旧比例挂起来像短款）。如果 `assets-src/photos/<slug>-measurements.json` 提供了实测数据，以实测为准；否则使用：

| 部位 | 默认值 |
| --- | --- |
| 衣长（肩颈点到下摆） | 0.76 m |
| 胸宽（平铺单层） | 0.60 m |
| 肩宽（落肩，肩缝落在上臂） | 0.58 m |
| 袖长（肩缝到袖口） | 0.26 m |
| 袖口宽（平铺） | 0.23 m |
| 下摆宽（平铺） | 0.59 m |
| 领口罗纹宽 | 0.025 m（偏厚的圆领罗纹） |

### 3.2 网格

- 由缝纫版片（前片、后片、两只袖子、领口罗纹）在 Blender 中缝合，挂在衣架上做布料模拟得到自然垂落形态。
- **模拟分辨率 = 导出分辨率**：模拟前就把网格定到最终密度，模拟后不得再减面、重拓扑或细分，否则动画形变目标的顶点序号会对不上。
- 单层约 3,500–5,000 顶点；之后用 Solidify 加厚 0.002 m，导出总计 ≤ 10,000 顶点、≤ 20,000 三角形。
- 必须有完整背面与真实厚度。领口内侧、袖口内侧、下摆在近看时可见。
- 下摆和袖口做出卷边厚度（rim 或额外 edge loop）；肩缝、侧缝在几何或法线上可辨识。
- 衣服与衣架无穿透；领口两侧被衣架肩部撑起，前后片自然下垂。

### 3.3 文件

| 文件 | 内容 |
| --- | --- |
| `public/models/tee.glb` | 静止垂落网格（无形变目标），供衣架上的所有 T 恤使用，网页首屏只加载这个 |
| `public/models/tee_anim.glb` | 同一网格（顶点序号与 `tee.glb` 完全一致）+ 形变目标 + 动画 `lift`、`return` |

两个文件的节点结构相同：

```text
HookPivot            空节点，位于原点；动画中携带整体刚体运动
  Hanger             衣架（与 hanger.glb 相同，可直接引用同一份几何）
  Garment            衣服网格，材质槽 Fabric（外层）、FabricInner（内层与卷边）
```

### 3.4 材质与贴图

- UV：前片与后片为两个独立岛，**正立且不镜像**，固定区域：
  - 前片身：U 0.00–0.48，V 0.40–1.00
  - 后片身：U 0.52–1.00，V 0.40–1.00
  - 袖子、领口罗纹等：V 0.00–0.38
- 全衣服纹素密度统一。另外导出 `public/models/tee_uv_layout.json`：每个岛的 UV 矩形、该岛在衣服上的物理尺寸（米）、肩颈点（HPS）与前后中线在 UV 中的位置，用于按物理尺寸放置印花。
- 共享贴图（嵌入 `tee.glb` 和 `tee_anim.glb`）：
  - `ORM` 2048²：R = 环境光遮蔽（在静止垂落形态下烘焙），G = 粗糙度（针织约 0.85），B = 0。
  - `Normal` 2048²：OpenGL 约定（绿色向上），包含平纹针织细节与缝线、卷边细节。
- 商品贴图（不嵌入，网页按商品替换）：`public/products/<slug>/basecolor.png`，2048²，sRGB，按上面的 UV 布局把底色、印花合成好。
- `FabricInner` 使用同一套 UV，网页端会把内层颜色压暗。

## 4. 烘焙动画

### 4.1 原则

- 衣架沿下面规定的路径做刚体运动，布料随之模拟。
- 刚体运动写进 `HookPivot` 节点的 translation / rotation 动画。
- 布料**相对衣架**的形变（即每帧顶点位置乘以衣架世界矩阵的逆）写成形变目标：每个采样帧一个 shape key，权重按帧一热（one-hot）打关键帧，相邻帧之间线性插值。
- 第 0 帧 = 静止基础网格本身（形变为零）。模拟需要先预跑约 3 秒让衣服完全静止，再开始计时。
- 场景 24 fps，逐帧采样。动画名必须正好是 `lift` 和 `return`。

### 4.2 路径（glTF 坐标：Y 向上，+Z 朝相机；单位米、度、秒）

`lift`：从横杆取下到近看位置，总长 1.5 s（36 帧）

| 时间 | HookPivot 位置 | 绕 Y 轴旋转 | 说明 |
| --- | --- | --- | --- |
| 0.00 | (0, 0, 0) | 0° | 挂在横杆上，静止 |
| 0.20 | (0, 0.07, 0) | 0° | 挂钩升离横杆，缓出 |
| 1.10 | (0, 0.05, 0.60) | 360° | 向前并整圈转身，缓入缓出 |
| 1.50 | (0, 0.05, 0.60) | 360° | 保持不动，布料自由甩动后落定 |

`return`：从近看位置挂回横杆，总长 1.25 s（30 帧）

| 时间 | HookPivot 位置 | 绕 Y 轴旋转 | 说明 |
| --- | --- | --- | --- |
| 0.00 | (0, 0.05, 0.60) | 0° | 近看位置，静止 |
| 0.70 | (0, 0.07, 0) | 0° | 退回横杆正上方，缓入缓出 |
| 0.85 | (0, 0, 0) | 0° | 落钩，缓入 |
| 1.25 | (0, 0, 0) | 0° | 落钩后小幅摆动并静止 |

`return` 的第 0 帧必须与 `lift` 最后一帧接近（都是近看位置静止状态），最后一帧接近基础网格，避免网页切换时跳变。

## 5. 商品贴图流程

输入：`assets-src/photos/<slug>-front.<ext>`，可选 `<slug>-back.<ext>` 与 `<slug>-measurements.json`。`<slug>` 形如 `shirt3`，扩展名可能是 jpg、jpeg、png、webp、avif。

现有照片是电商商品图（棚拍平铺或隐形人台），不是标准俯拍；个别是穿在模特身上的背面照（如 `shirt4-back`），只能参考印花内容与位置，需要校正透视和遮挡；部分照片分辨率只有约 450 像素，印花放大后会糊，需要在报告里注明。没有背面照的款式，背面用纯底色，只保留领口内标。

> **授权说明**：这些照片是第三方品牌（Fear of God / Essentials、NBA、MLB 等）的商品图，带有其商标。经项目拥有者确认，仅用于私有仓库和私有演示；网站公开上线或卖货前必须全部换成原创或有授权的设计。

处理：

1. 去背景、透视校正，按衣服轮廓把照片对齐到版片。
2. 取出布料底色（排除印花与阴影后的中位色）。
3. 抠出印花，得到透明背景的 `print_front.png`、`print_back.png`，并去除平铺褶皱、阴影、反光。
4. 按印花在照片中的物理位置与尺寸，合成到 UV 布局上得到 `basecolor.png`。布料纹理来自共享法线贴图，不使用照片里的布料。
5. 写 `public/products/<slug>/product.json`：`slug`、`baseColorHex`、印花位置（距肩颈点的距离、宽度，单位米）、尺寸来源（实测或默认）、照片文件名。

抠印花失败或不确定时停下来报告，不要臆造图案。

## 6. 验收输出

放在 `assets-src/reports/<资产名>/`：

- 静止状态渲染：正面、背面、左侧、右侧、正面 3/4、背面 3/4。背景暖灰 `#ecebe4`，柔和主光加环境光。
- `lift` 与 `return` 每 4 帧一张的拼图。
- 把导出的 `tee_anim.glb` 重新导入后的渲染（验证导出本身没问题）。
- `report.json`：Blender 版本、顶点数与三角形数、包围盒、形变目标数、动画时长、贴图尺寸、使用的版型尺寸、已知问题。

自检清单：

- [ ] 背面文字不是镜像
- [ ] 衣服不穿透衣架，挂钩内侧顶部接触点在原点（顶部金属允许高出约 0.004 m）
- [ ] `tee.glb` 与 `tee_anim.glb` 顶点数和顺序一致
- [ ] glTF 中正面朝 +Z
- [ ] 动画名为 `lift`、`return`，节点名与第 3.3 节一致
- [ ] 印花物理尺寸与照片一致
